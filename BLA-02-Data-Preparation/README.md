# BLA 02: Data Preparation for Machine Learning and AI

## Purpose

This BLA explains how data is collected, stored, transformed, and checked before it is used in machine learning and AI systems. It is based on Domain 1 of the AWS Certified Machine Learning Engineer – Associate MLA-C02 certification.

## Part 1: Collecting and Storing Data

Part 1 explains where machine learning data comes from and how it can be moved and stored on AWS. It discusses batch and streaming ingestion, AWS storage services, file formats, structured data, unstructured data, and multimodal data.

## Part 2: Data Transformation and Feature Engineering

Part 2 explains how raw data is converted into useful input for machine learning models. It covers preprocessing, feature engineering, SageMaker Feature Store, embeddings, RAG document preparation, and the protection of sensitive information.

## Part 3: Data Quality, Labeling, and Bias

Part 3 explains how to determine whether data can be trusted. It covers data-quality dimensions, missing values, duplicates, outliers, labeling, class imbalance, bias, data leakage, and training-data integrity.

## AWS Services and Technologies Discussed

- Amazon S3
- Amazon Kinesis Data Streams
- AWS Glue
- AWS Glue DataBrew
- Amazon EMR
- Amazon SageMaker Data Wrangler
- Amazon SageMaker Feature Store
- Amazon SageMaker Ground Truth
- Amazon SageMaker Clarify
- Amazon Bedrock

## Lessons Learned

I learned that preparing data involves more than cleaning a dataset. The complete process includes collecting, storing, transforming, validating, labeling, and checking data for quality and bias. I also learned that the same preparation rules should be used consistently during training and inference.
