# AWS MLA-C02 Model Development

This folder contains my presentations and transcripts about ML Model and Foundation Model Development for the AWS Certified Machine Learning Engineer – Associate MLA-C02 certification.

The content is divided into three parts:

- Part 1 explains how to choose machine learning models, foundation models, and managed AWS AI services.
- Part 2 covers model training, hyperparameter tuning, fine-tuning, and customization.
- Part 3 discusses model evaluation, explainability, drift detection, and continuous improvement.

This folder also includes links to the related YouTube videos and LinkedIn posts.
